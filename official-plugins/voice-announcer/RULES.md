# 行为规则（voice-announcer 项目资产）

本文件是声律插件的规则资产，随项目版本管理。规则不依赖个人记忆维护，以本项目文件为准。

## 中文思考规则

- 所有思考、推理、分析过程——包括 thinking 标签内的内容、MOOD 模块、工具调用前的推演——必须使用中文，禁止英文思考。
- 代码、变量名、API 名称、工具名等专有名词保留原文，但围绕它们的解释、分析、推理必须用中文。
- 最终回答在用户使用纯英文提问时可以用英文，思考推理过程依然保持中文。
- 本规则由声律插件自身负责运行时注入：extensions/rules-inject.js 在 before_agent_start 时把启用中的规则注入 system prompt（v0.2.8 起，此前依赖 chinese-thinking 插件注入，已并入本插件）。本文件管项目资产与分发。

## 卡片收尾规则

- 收尾必须卡片：总结、结论、流程、选项对比、数据/状态汇报、决策建议，一律用 show_card 卡片展示，不得只用纯文字收尾。
- 按内容形态选型，不一律套模板：结论摘要用简洁陈述卡；流程/架构用图示卡；选项对比用对比卡；数据汇报用指标卡；内容越复杂，卡片结构化程度越高。
- 分工：正文讲过程，卡片给结论。卡片只承载关键信息，信息密度高、一眼可读，不与正文重复叙述。
- 豁免：一句话确认、纯闲聊、简短问答等低信息量收尾，不强行出卡。
- 规范：卡片遵守 hana_card_guide 设计手册（纸张风、宿主主题变量、无渐变阴影光效、无 emoji），保证跨主题可用。
- 适用范围：Hana 在本项目相关会话中的回复收尾；声律插件配合该规则，把收尾内容同步朗读。

## 命令执行优先级

- 本项目相关会话中执行命令，按以下优先级选择通道，不得默认 PowerShell：
  1. 文件操作优先用结构化工具（read/grep/find/ls/edit/write），不进 shell
  2. 复杂逻辑、文本处理、编码敏感任务用 Python 3.13（python -c 或临时脚本）
  3. 极简内置命令用 cmd（dir/copy/type 等）
  4. 必须用 PowerShell 时只用 pwsh 7（默认 UTF-8、支持 &&）
- 禁止用默认 PowerShell（5.1）写 POSIX 语法；禁止把 Linux heredoc、sed/awk 管道习惯搬进 Windows。
- 特例：插件内部 TTS 桥接的常驻 PowerShell 进程为既定实现，不受本规则约束。

## 临时文件规范

- 任务过程中生成的临时文件（一次性脚本、中间数据、下载文件、测试产物）一律写入当前工作区 `_tmp/` 目录，禁止散落在工作区根目录或项目目录。
- `_tmp/` 内按类别分子目录存放：
  - `_tmp/scripts/` — 一次性脚本（py / cjs / mjs / ps1 等）
  - `_tmp/data/` — 抓取数据与中间产物（txt / json / csv 等）
  - `_tmp/downloads/` — 临时下载文件
  - `_tmp/tests/` — 测试与验证产物
  - `_tmp/misc/` — 其他无法归类的临时文件
- 任务收尾按「产物清理纪律」判断去留：该删的当场删；需要短暂保留的留在 `_tmp/` 对应类别中。
- `_tmp/` 整体可随时清空，不影响任何项目资产。

## 播报规则

- Hana 回复完成后自动朗读（默认开启，可在插件设置中关闭）。
- 默认音色：Microsoft Xiaoxiao Online（Edge 在线语音，经 NaturalVoiceSAPIAdapter 桥接为系统 SAPI 语音）。
- 音色不可用或断网时，自动降级本地音色（Microsoft Huihui）。
- 超过最长朗读字数（默认 500 字）时截断朗读，不整篇念完。
- 仅播报 role 为 assistant 的正式回复文本；tool 调用中间消息、thinking、后台任务结果不播报。
- 多消息串行播放，不重叠出声。

## 选项卡片规则

- 需要用户做选择、确认或决策（选方案、确认操作、要偏好、多选一）时，优先使用 `option_card` 工具在对话中渲染可点击选项卡片，而不是用纯文字提问让用户打字回复。
- 即使只有 2 个选项（如 是/否、A/B 二选一）也要用选项卡片，不要降级为纯文字提问。
- 无决策点、答案唯一、需要自由文本输入时，不使用选项卡片（普通对话即可）。
- 选项 2~6 个：≤3 个自动横排并排，>3 个自动竖列。
- 卡片底部提供两个逃逸通道：「自定义输入」（展开输入框，用户自由填写）与「跳过」（不做选择）。
- 回传消息格式（均以「（选项卡片）<问题>」开头）：
  - 点击选项 → 「我选择：<选项>」；收到后视为选择结果，直接接续对应分支执行，不重复提问。
  - 自定义输入 → 「我选择（自定义）：<内容>」；收到后视为用户自由输入，按其内容继续。
  - 跳过 → 「跳过，不做选择」；收到后视为用户放弃该决策，不追问，按默认处理或结束该话题。
- 会话正在流式输出时点击会失败（session_busy），卡片前端已做提示；向用户说明等回复结束再点即可。
