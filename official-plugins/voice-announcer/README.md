# 语音播报（voice-announcer）

**让 Hana 开口说话：回复自动朗读，晓晓音色，边生成边读。**

## 它解决什么问题

- **看不过来**：长回复、日报、总结要盯着屏幕读，忙别的事时信息就漏了
- **不想看屏幕**：做饭、通勤、干活时，希望 Hana 的内容像播客一样「听」完
- **错过播报**：普通方案要等整段回复结束才读，生成时间长时等得着急
- **配置繁琐**：其他 TTS 方案要装驱动、配接口、生成音频文件，门槛高

这个插件把这些全部解决：装完即用，回复自动开口，实时模式生成一句念一句，插话随时打断。

## 适合谁

- **Hana 桌面端用户**：希望与 AI 有「声音交互」而非纯文字的人
- **多任务场景**：写代码、做家务、开车（听）时不想盯屏幕的人
- **日报/资讯读者**：每天让 Hana 读新闻、总结、知识库内容的人
- **视障或弱视用户**：更依赖语音获取信息的人群

## 它能做什么

| 能力 | 说明 |
|------|------|
| 自动朗读 | 回复完成后自动朗读，零点击 |
| 实时朗读 | 边生成边读，句子级流式（可选开关） |
| 晓晓音色 | Edge 在线神经语音，中英混读音色统一 |
| 卡片朗读 | show_card 卡片里的总结、结论一并念出 |
| 智能打断 | 插话、新建会话立即停播 |
| 格式清洗 | markdown 符号、链接、邮箱不念，只念正文 |
| 侧边栏面板 | 开关、音色（11 种）、语速、长度随时调 |
| 即装即用 | 内置语音桥接，自动安装，无需手动配置 |

## 快速开始

1. 安装插件，授予完整权限
2. 首次运行自动检测并安装语音桥接（弹一次 UAC，点「是」）
3. 完成。对 Hana 说句话，回复自动朗读

## 系统要求

- Windows 10/11
- HanaAgent 0.82.0+
- 联网（在线音色；断网自动降级本地音色）

## 配置

| 配置 | 默认 | 说明 |
|------|------|------|
| 自动播报 | 开 | 回复完成后朗读 |
| 实时朗读 | 关 | 边生成边读 |
| 音色 | 晓晓 | 11 种在线/本地音色 |
| 语速 | 0 | -10 ~ 10 |
| 长文截断 | 500 字 | 超长只念开头 |

## 技术说明（简）

插件监听 Hana 会话事件，文本清洗后交给 Windows SAPI 5 实时合成；语音由内置的 NaturalVoiceSAPIAdapter（开源，Apache-2.0 生态）桥接 Edge 在线神经语音。常驻进程消除启动延迟，句子合并降低网络调用。详见项目内文档。
