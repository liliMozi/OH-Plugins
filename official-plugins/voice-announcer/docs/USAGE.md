# 使用指南

## 两种播报模式

侧边栏「播报」面板里有两个开关，可以同时开：

| 开关 | 效果 |
|------|------|
| 回复完成后朗读 | 默认模式。Hana 整段回复结束后，一次性朗读全文 + 卡片内容 |
| 实时朗读 | 边生成边读。Hana 生成一句，晓晓念一句，不用等回复结束 |

两个都开时，实时模式优先；实时模式下回复末尾的卡片内容也会在最后补读。

## 侧边栏面板

右侧栏找到「播报」按钮（喇叭图标），面板提供：

- **开关**：总开关（关闭后完全不朗读）
- **实时朗读**：切换边生成边读
- **音色**：11 种可选
  - 在线：晓晓、晓伊（女），云希、云扬、云健、云夏（男），晓北、晓妮（女）
  - 本地：慧慧、康康、瑶瑶（断网时自动降级使用）
- **语速**：滑杆 -10（慢）~ 10（快），默认 0
- **长文截断**：超过该字数的回复只念开头，避免念一篇论文
- **立即停止**：随时掐断当前朗读
- **测试声音**：用当前设置试读一句

## 打断

- 你在 Hana 朗读时**发送任何消息**（插话、新建会话），朗读立即停止
- 新回复会自动开始新一轮朗读
- 侧边栏「立即停止」按钮等效

## 朗读内容

- 回复正文（清洗掉 markdown 符号：星号、标题、列表等不念）
- `show_card` 卡片内的文字内容（总结、结论、表格文字）
- 思考过程（thinking）、内部情绪（mood）、工具调用细节**不朗读**
- 裸链接（https://...）、www 域名、邮箱地址**跳过不念**

## 中英文

- 英文段落由晓晓直接朗读，音色统一、无缝衔接
- 中文数字、英文单词、URL 等正常读

## 音色提示

- 在线音色音质好但需要联网
- 断网时自动降级本地音色（慧慧等），恢复联网后自动切回
- 切换音色后立即生效，无需重启
