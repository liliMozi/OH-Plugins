# 常见问题（FAQ）

## 没有声音

1. **检查开关**：侧边栏「播报」面板，总开关和实时开关是否开启
2. **检查依赖**：见 [INSTALL.md](INSTALL.md) 的手动验证，系统语音列表里应有 `Microsoft Xiaoxiao Online`。没有则插件安装依赖时 UAC 可能被拒，重新加载插件再试
3. **检查音量**：Windows 音量合成器里 Hana 的音量、系统总音量
4. **检查网络**：在线音色需要联网（走 Edge 语音服务）。断网会降级本地音色，如果本地音色也没声音，检查 Windows 语音设置

## 声音是本地音色（不是晓晓）

- 在线语音不可用（断网 / 桥接未安装 / Edge 语音服务临时故障），自动降级为本地音色
- 检查系统语音列表是否有 `Microsoft Xiaoxiao Online`；有则可能是网络波动，稍后自动恢复

## 念出来的内容有奇怪符号（星号、井号）

- 旧版本会把 markdown 标记念出来，升级到 v0.1.5+ 即可（已自动清洗）
- 确认插件版本：设置页插件列表查看

## 英文念得不像英文 / 被跳过

- v0.1.1+ 英文由晓晓直接混读，音色统一
- 若英文整段缺失，检查是否旧版本，升级即可

## 实时朗读没生效（还是完成后才读）

- 确认侧边栏「实时朗读」开关已打开
- 实时模式依赖流式事件，如果 Hana 在生成中调用大量工具，中间过程可能短暂停顿，属正常
- 升级到 v0.1.5+（修复了工具链事件误打断）

## 语速太快 / 太慢

- 侧边栏「语速」滑杆调节，-10 到 10，改完即时生效

## 朗读被打断后不恢复了

- 插话打断后，新回复会自动重新朗读。如果连续插话，朗读会持续让位，属正常设计

## 插件装了但侧边栏没有「播报」按钮

- 检查插件是否启用、是否授予完整权限
- 重启 Hana 后侧边栏按钮应出现

## 播报延迟明显（完成模式）

- 常驻进程预热后延迟约数百毫秒。如果刚开机/刚装插件，首次朗读需要预热，会稍慢
- 实时模式可消除「等回复完成」的感知延迟

## 其他程序用不了晓晓？

- 桥接组件安装后，系统所有 SAPI 程序都能用在线语音（Edge、Word 朗读、Balabolka 等），这是组件的额外福利
